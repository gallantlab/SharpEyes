# Citing SharpEyes

If you use SharpEyes in your work, please cite it using the following:

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20401807.svg)](https://doi.org/10.5281/zenodo.20401807)

## BibTeX

```bibtex
@software{sharpeyes,
  author    = {Zhang, Tianjiao and Gallant, Jack L.},
  title     = {gallantlab/SharpEyes},
  year      = {2026},
  publisher = {Zenodo},
  version   = {0.7},
  doi       = {10.5281/zenodo.20401807},
  url       = {https://doi.org/10.5281/zenodo.20401807}
}
```

## Plain text

Zhang, T. and Gallant, J. L. (2026). *gallantlab/SharpEyes* (v0.7). Zenodo. https://doi.org/10.5281/zenodo.20401807
